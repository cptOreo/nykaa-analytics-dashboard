# Nykaa Fashion vs Beauty Analytics Dashboard

An interactive, multi-page Dash web application exploring the profitability gap between Nykaa's Beauty (BPC) and Fashion segments. Built with Python, Dash, and Plotly, this dashboard visualizes financial metrics and synthetic customer survey data using Nykaa's brand visual language.

## Features
- **8 Interactive Pages**: Covers Executive Overview, Margin Gap, Growth vs Profitability, Customer Economics, Acquisition, Returns, Platforms, and Break-even scenarios.
- **Dynamic Filtering**: Slice synthetic customer insights by Age Group and Primary Platform.
- **Scenario Simulator**: Interactive sliders to model the impact of operational changes on break-even volume.
- **Nykaa Branding**: Custom CSS and Plotly themes reflecting the Magenta and Charcoal aesthetic.
- **De-slopped Copy**: Simple, direct, and conversational analytical insights.

## Running Locally

1. Create a virtual environment:
   `python3 -m venv .venv`
2. Activate it:
   `source .venv/bin/activate`
3. Install dependencies:
   `pip install -r requirements.txt`
4. Run the app:
   `python app.py`

Navigate to `http://localhost:8050` in your browser.
